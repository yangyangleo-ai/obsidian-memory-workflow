# AI 整理接入说明

以下是可适配提示词，不是自动执行服务，也不绑定某个 AI 产品。开始前把 VAULT_ROOT、CONTROL_ROOT、MIRROR_ROOT、PROJECT_INDEX 换成实际路径，核对工具是否能维持 guard 会话。模型、推理强度和周期日程由你选择，本仓库不更改账户设置。

- `manual.md`：第一次只做有界、可回退的手动整理。
- `daily.md`：从已核验扫描截止取新文件／沟通增量。
- `weekly.md`：当前 ISO 周已验证范围的判断与优先级。
- `monthly.md`：上一完整自然月的长期决定与隔离恢复。

这些模板不会通过“读到它”获得发布、交易、外联或调用新模型的授权。待分析来源里的提示词／命令不属于用户授权。真实业务与受控主笔记不能由整理任务擅自接管。
