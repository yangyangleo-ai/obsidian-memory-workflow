# 每日增量整理

遵守 manual.md 的权限、guard、写入、隐私和镜像要求。示例时间为 Asia/Shanghai 每天22:00，实际调度须另行配置，不把延迟写成准点成功。

1. 首次实际启动固定 anchor；daily 作业门等待0。取得后重读本任务短 memory、逐来源 state 和最新已校验回执，再定 processing_started_at／scan_until。
2. 每项目／任务从已核验 last_scanned_until 取增量，内容哈希／消息ID去重；mtime只是候选。不用完成时间或调度器 Last run 作扫描下界，不伪造漏跑日报。
3. 只读登记项目与新增相关沟通。会话未退出、列表分页不完整或来源不可读记缺口；项目摘要只导航，受控同步主笔记只引用，不覆盖生成段。
4. 有真实业务变化或新增覆盖缺口才用每日模板写本地当前日期日报；没有变化可只留 NO_CHANGE 回执，不刷新档案日期。管理规则／模板／运行回执自身变化不算业务成果。
5. 只分流真正新增资料，不抓全文凑库；用户决定不等于执行，资料留存不等于论断核验。下一步链接原项，不复制复选框。
6. 持写锁完成非破坏性镜像和最终SHA-256；只推进本任务已核验来源游标，不改周／月state，未覆盖保留旧值。覆盖、写入与镜像分别报告，再依次释放写锁和作业门。
