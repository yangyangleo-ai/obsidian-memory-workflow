# 每周知识复盘

遵守 manual.md 的共同要求。示例时间为 Asia/Shanghai 周日22:30；weekly 作业门等待最多3600秒，同类重入退出，跨类等待不读取旧快照、不并发扫描；超时记 DEFERRED_LOCK，不推游标。

1. cycle 使用首次anchor的ISO周所属年份／周号。取得作业门后重读最新日回执、state与本任务指纹；同周期同输入已发布不重写，不补造漏周。
2. 优先合格日报、NO_CHANGE／PARTIAL回执与验收来源，再按变化读主笔记。日任务PARTIAL不阻断全部范围；沟通、日期、原件和晚到尾段缺口保留。
3. 周报记录真实变化、有效／失效判断、反证、风险与最多三个优先级。只引用原任务／唯一主笔记，不复制业务状态和待办。
4. 只复查本周变动资料／方法和已有复查提示；有来源、适用边界、反例与再核实条件才提炼知识卡，不以卡片数量考核。
5. 写前另取write guard，逐文件备份／比较，镜像全库必需源并核SHA-256。部分发布与完整覆盖标记分开，不改日／月state，不恢复暂停项目；按顺序释放两个guard。
