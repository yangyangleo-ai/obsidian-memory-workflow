# 常见问题

**这是 Obsidian 插件吗？** 不是，是文件、规则和辅助脚本的起步包，不修改 Obsidian 程序。

**必须用 Codex／某个模型吗？** 不需要。手动即可；要接 AI，需自己配置工具权限、文件读取和调度能力，费用由该服务决定。

**下载后会自动每天运行吗？** 不会。模板、提示词和 guard 不是调度器；仓库不会创建定时任务、运行后台 Agent 或恢复暂停业务。

**可以直接覆盖旧库吗？** 不建议。先在新示例库练习，再逐个引入规则和模板；不要批量移动旧笔记或复制应用配置。

**私密标记能阻止上传吗？** 不能。publish:false、private 和 Bases 过滤都不是 Git／文件权限。真实库放公开仓库外，发布前仍检查文件白名单和内容。

**为什么镜像文件数可能更多？** 目标额外历史文件会保留；必需集合是源文件，不能为数量一致删文件。sha256_difference_count=0 只描述已经核验的范围。

**为什么月报可能是 PARTIAL？** 有些沟通、日期或项目缺证据。可以发布已核验范围的复盘，但未覆盖范围不能写成无变化或全部完成。

**脚本支持哪里？** Python 工具针对普通本地目录，拒绝链接／重解析点；guard 支持基线是 Windows PowerShell 7。其他文件系统、网络盘、云占位文件、权限／ACL、恶意并发者需要另行验收。

**复制哈希一致是否意味着能完整恢复系统？** 不意味着。工具核验文件字节与路径，不备份应用进程状态、数据库一致性、ACL、云账户或外部服务；整机／异机灾备是另一层工作。
