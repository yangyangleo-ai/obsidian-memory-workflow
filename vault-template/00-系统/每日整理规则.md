# 每日整理规则

示例安排每天22:00，不会自动调度。实际开始记录 UTC anchor；取得作业门、重读 state／回执后固定 scan_until。逐来源从上次已核验截止取增量，不拿完成时间作下界，不补造关机期间日志。

1. 只检查登记且有内容／消息变化的项目；mtime只是候选，清单／哈希／消息ID去重。读取失败保留缺口，不能写无变化。
2. 有真实变化或新缺口才使用 [[06-模板/每日记录模板]]；没有变化可仅留库外 NO_CHANGE 回执，不刷新项目日期。
3. 新资料用 [[06-模板/资料摘录模板]]，保存不等于核实；项目当前结论只落唯一主笔记，受控同步生成段只引用。
4. 日报下一步链接原任务，不重复创建独立复选框；暂停项目不推进。
5. 持写锁完成逐文件备份／哈希重读、非破坏性镜像和最终SHA-256核验。覆盖／写入／镜像分开，成功后只推进本任务已核验来源。
6. 最后先释放写锁再释放作业门并确认退出。忙／超时不删除锁，不推游标。

模板／治理规则／运行回执自身变化不算业务成果；本库所有源文件仍纳入镜像必需集合。完整工具使用步骤见 GitHub 项目 docs/operations.md。
